# sandhorse-tinytorch

A from-scratch implementation of an ML framework inspired by [TinyTorch](https://github.com/harvard-edge/cs249r_book/tree/main/tinytorch), built while working through Harvard CS249r's ML Systems course.

## What I'm Learning

The goal is not just to use ML frameworks, but to understand how they work underneath.

I'm implementing core components from scratch with Python and NumPy, including:

- Tensors and broadcasting
- Neural network layers and activations
- Loss functions
- Autograd
- Optimizers
- Training loops
- Convolutions and CNNs
- Tokenization, embeddings, and attention
- Transformer components
- ML systems concepts such as profiling and optimization

## Progress

Currently working through the modules incrementally, implementing the components myself and testing them along the way.

This repository is my working record of that process — including implementations, tests, notebooks, experiments, and notes.

## Tech Stack

- Python 3.10+
- NumPy
- Pytest
- Jupyter
- Quarto

## Why I'm Building This

I want to move beyond simply using ML libraries and develop a deeper understanding of the systems underneath them.

> Build it yourself. Understand what happens underneath.
